# Nation info screen

Right-clicking a nation's name in a nation list opens this window.

## How to open

- Game Tools > Create a Pretender God > era > Select Nation: right-click on the nation's name text (left click picks it and opens the nation overview with Ok/Cancel instead). *(game screen, 2026-10-26)*
- Return closes it and the list stays where it was; Escape from the Select Nation list goes straight back to Game Tools. *(game screen, 2026-10-26)*

## Layout

- Title tab with the nation's name and epithet; the nation's banner top left and top right. *(game screen, 2026-10-26)*
- Description on a parchment panel, then a 'National Features' bar, then lines: Race, Military, Magic, Priests, Scales & Blesses, Buildings. *(game screen, 2026-10-26)*
- A dark panel below with labelled sprite rows: Commanders, Units, Sites (start sites as square icons); a single Ok button at the bottom. *(game screen, 2026-10-26)*
- The sprites are the nation's recruitables including capital-only ones: Ulm shows 12 commanders (8 + 4 capital-only) and 17 units (16 + 1 capital-only), as the inspector lists. *(game screen, 2026-10-26)*
