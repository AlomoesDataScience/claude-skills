# Pretender design screen

Game Tools > Create a Pretender God > era > nation > Ok. Exact click positions: dom6-pretender-ingame SKILL.md.

## Hotkeys (press ? on the screen)

- ctrl-l load a pretender design; ctrl-s save current design; ctrl+shift-s save pretender as AI template mod data. *(game screen, 2026-10-27)*
- a add bless effect; b view all possible bless effects; x repeat add last bless effect. *(game screen, 2026-10-27)*
- i / F view forgeable magic items; s / F5 / C view researchable spells; n view nation description; p select physical form; r random pretender; t templated pretender. *(game screen, 2026-10-27)*

## Spells view (s)

- "Magic Schools" menu: Conjuration, Alteration, Evocation, Construction, Enchantment, Thaumaturgy, Blood Magic, Divine; each opens that school's spells for this nation and god. *(game screen, 2026-10-27)*
- Each school's list shows ALL spells by research level (not only the god's), scrolling. Row: path icons (repeated per level), second path, a pentagram = ritual, name, gem icon + gem cost. Escape goes back to the design screen. *(game screen, 2026-10-27)*

## Items view (i)

- "Browse Magic Items": a tab row of slot types (one-hand, two-hand, bow, shield, helmet, body, boots, misc...), then rows by rarity: Trinkets, Lesser Magic Items, Greater Magic Items, Very Powerful Magic Items, Unique Magic Artifacts. Hover = name tooltip "(right click for info)"; right-click = the item's info. *(game screen, 2026-10-27)*
- Item level = Construction research needed: Trinkets 1, Lesser 3, Greater 5, Very Powerful 7, Unique Artifacts 9 (inspector constlevel, modding manual). *(game screen + modding manual, 2026-10-27)*

## Magic panel

- Path icons in order Fire, Air, Water, Earth, Astral, Death, Nature, Glamour, Blood, each with its level; hover tooltip "Fire magic" etc. These are the path_* templates in dom6-ui. "New paths cost N points", "Custom Priest Spells: ..." (change with the god's paths: Banishment, Smite for a Water god; Final Rest, Word of Thorns for Earth/Nature). *(game screen, 2026-10-27)*

## Dominion panel

- Icons: candles (dominion strength), dove (Order/Turmoil), hammer (Productivity/Sloth), sun (Heat/Cold), wheat (Growth/Death), clover (Luck/Misfortune), purple orb (Magic/Drain). A line under them sums the effects, e.g. "Income +16%, Unrest reduction +3, Rec Points +30%, Resources +39%, Supplies +10%, Growth +0.20%, Events -6%" for Order 3 Prod 2 Growth 1. *(game screen, 2026-10-27)*

## Bless panel

- Hovering a bless shows its effect as a tooltip ("Blessed units will be very resistant to getting permanent battle afflictions (75% protection from afflictions)"). *(game screen, 2026-10-27)*
