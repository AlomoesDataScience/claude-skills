# Rituals (Dominions 6, vanilla)

The user's list (2026-11-03). Manual p.28 (labs), pp.55-56 (turn order), pp.77-78 (globals, dispel); illwiki
`magic` ("Casting Rituals").

## The rules
- Cast on the strategic map, only in a province with a **lab**; takes the mage's whole turn; costs gems
  (or slaves) from his inventory or the pool (p.28; wiki).
- Battle gem rules don't apply: gems can't raise the level. Only items, other rituals and some sites boost
  a ritual caster (wiki). Extra levels still add effect (more units, more range, more damage).
- Dual-path rituals use gems of the first path (p.74).
- Range in provinces; Far Caster items and Infernal Circle (blood) add range.

## Kinds
Summons (dom6-summoning), site searches (dom6-site-search), remote attacks (Fires from Afar, Storm, Curse...),
scrying and teleports (Teleport, Cloud Trapeze), province enchantments, global enchantments, alchemy, healing
(Blood Feast), dominion and scale changers.

## Turn order (p.55-56)
Rituals (10, random order between mages) -> remote attacks (11) -> magic battles: teleports/wind rides fight
(12) -> site searches (14) -> ... movement (24-25) -> battles (26) -> globals take effect (28) -> special
orders like Reanimate (36). So a teleporting thug fights before normal armies move; a remote attack hits an
army before it moves.

## Globals (pp.77-78)
One copy of each in the world; casting an existing one is a dispel attempt (+1 per extra gem, +5 per level
over, + DRN each side); Grand Communion pools mages. Battle enchantments end when their caster dies (p.75); globals are
removed by dispelling. Details: dom6-gem-casting.
