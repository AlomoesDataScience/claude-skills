# Dominions 6 - lexicon (war-language)
Game element <-> doctrine term. From the manual (pages), the mechanics skills (dom6-*) and play (Pythium,
Tir na n'Og SCBM). Extend whenever something new appears. Two levels: the strategic map (operations) and the
autobattle (tactics, run from the setup - no live control).

## 1. Units -> roles
| game unit/type | arm | natural tasks | never |
|---|---|---|---|
| Heavy infantry (high prot, shields) | heavy foot | fixing force, block, hold the line, screen the mages | chase cavalry |
| Light / chaff infantry, PD | levy / screen | absorb the first charge, fill squares, soak harassment onto a thug | count as combat power |
| Archers, slingers (Fire, Fire closest) | shooters | support by fire, concentrated on one squad | stand where cavalry reaches them first |
| Cavalry, centaurs (Attack, target archers/rearmost) | shock / mobile | envelop round the flank, strike shooters and mages | charge into high defence + armour-piercing blocks |
| Sacreds (blessed) | elite heavy | main effort | be wasted as chaff |
| Mages (Stay behind troops, scripts) | fires / support | buffs rounds 1-2, evocations = attack by fire, battlefield enchantments | stand in front; cast themselves unconscious unscripted |
| Priests | support | Bless, Sermon/Fanaticism (morale), Smite | lead the charge |
| Thugs / SCs | strike / raid | kill what troops can't, solo raids on PD, counter-thug | go where their counter waits (dom6-supercombatants) |
| Scouts, spies (sneak) | reconnaissance | screen the front, report, park on routes | fight (Retreat + far rear) |
| Commanders (leadership) | command | lead squads (leadership, morale bonus) | exceed the squad limit (morale penalty) |
| God, prophet | main effort / C2 | dominion, bless incarnate, SC in friendly dominion | die without a recall plan |

## 2. Map -> terrain (OAKOC)
| terrain | movement | cover / effect | favours |
|---|---|---|---|
| Plains, farms | easy | none | cavalry, big armies; good supply |
| Forest | slower (survival skills help) | more sites; ambush, stealth | forest-survival units |
| Mountains, highlands | slow | passes = chokepoints (key terrain) | defenders |
| Swamp | slow | | swamp-survival units |
| Rivers | crossing costs, some impassable (red dots) | obstacles | defenders |
| Sea | only aquatic/amphibious/sailing | separate theatre | water nations |
| Forts | | supply, resources, sieges (dom6-sieges) | defenders; key terrain |
| Dominion (candles) | | +-1 morale, god/prophet stats | the believer - "terrain" of faith |

## 3. Mechanics -> effects
| game rule | doctrine effect |
|---|---|
| Morale checks, army rout at 75% lost (dom6-morale) | break cohesion, not bodies |
| Harassment (-1 defence per attack) | concentration / mass at the decisive point |
| Squad orders (Attack, Fire, Hold and attack, target) | tasks - fix, support by fire, attack by fire, envelop |
| Scripts (5 orders + general order) | the whole battle plan is written before contact |
| Round limits 100/150/170/200 | time: buffs end at 100; attackers rout at 150 |
| Stealth vs patrol roll | reconnaissance and counter-reconnaissance |
| Supply, starvation, forts' admin | sustainment, lines of communication |
| Dominion spread | the information/psychological line of effort; "wall of faith" = defence in depth |
| Hard counters (armour/AP, dodge/many attacks...) | matchups - task-organize for the likely enemy |

## 4. Victory -> end state
Thrones of Ascension (claim the required number) or elimination (no dominion = eliminated, dom6-dominion).
Decisive conditions: enemy main army and god destroyed or contained; their thrones and capital taken.

## 5. Control measures on the province map
Phase line = a ring of provinces by a turn ("hold the river line by turn 20"); objective = a province or fort;
axis = a chain of provinces; boundaries between our armies = which commander takes which provinces.

## 6. Back-translation: task -> game orders
| doctrine task | game orders | check after |
|---|---|---|
| fix | heavy squads Hold and attack in front; mages buff them | battle log: they held 2 rounds, then engaged |
| attack by fire | archers Fire (target: the squad to break); evokers scripted at that squad | kills and routs in that squad |
| envelop | cavalry on a flank, Attack target archers/rearmost | they reached the rear (replay) |
| screen | chaff squad in front; scouts on Patrol/Sneak forward on the map | what touched the screen first |
| guard (commander) | squad Guard commander, or bodyguards | mage alive at the end |
| reserve | a commander set to Hold, then Attack (scripted waits) | committed when the line wavered |
| raid | thug or small army sneaking/moving to a PD-only province | province taken, raider alive |
| delay | PD + small force in a fort province on Defend (besieged, buys turns) | turns bought vs force lost |
