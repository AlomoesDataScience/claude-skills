## The rules (Claude's summary)

Seven abilities (the letters F A S E R I P) rated in named ranks, each with a rank value (book
p9): Zero 0, Terrible 2, Bad 4, Average 6, Decent 10, Great 20, World Class 30 (peak human),
Fantastic 40, Astounding 50, Wondrous 75, Phenomenal 100, Single-Shift 150, Double-Shift 200,
Triple-Shift 500, Planetary 1000, Stellar 3000, Cosmic 5000, Infinite. Damage often equals the
rank value (Fantastic Strength hits for 40). Modifiers are **rank shifts** (+1 RS, -2 RS).
Actions roll percentile dice on the **universal chart** (back cover): the column is the rank, the
result is Fail, Bronze, Silver or Gold; a feat says which result it needs. The user's sheets write a
rank name with a small number after it (World Class 3, Fantastic 5, Astounding 8): check with
him what that number is (likely the point cost) before stating it. Health comes from the physical abilities; **Karma** is spent to boost rolls
and earned by heroic behaviour (and lost for unheroic acts). Advanced FASERIP adds point-buy
creation (the user's sheets: power points, ability points, benefit points), and rules for bases,
devices and robots.

Book map (PDF pages): introduction 6, basic system 8, character creation 11, combat 30,
environment 40, karma 44, getting better 49, equipment and bases 53, allies and enemies 61,
running the game 64, power descriptions 72, reference tables 118.
