# Claude Skills for learning, playing and designing games

Skills for [Claude Code](https://claude.com/claude-code) built while Claude learned a library of strategy games
(4X, operational and board wargames, Dominions 6, roguelikes, tabletop RPGs), plus the tools they use.
Only skills and tools are here: no game files, manuals, data dumps or screenshots.

## Install

**Whole set:** clone this repository and start Claude Code inside it. The generic skills in
`.claude/skills/` load at once; each game's skills (`Games/<Genre>/<Game>/.claude/skills/`) load when
Claude works in that game's folder. Put your own manuals and files into the matching game folders.

**Only the generic skills, everywhere:** copy the folders in `.claude/skills/` to `~/.claude/skills/`.
Game skills find the generic ones by walking up to a parent's `.claude/skills/`, so keep them inside
this tree (or copy the generic skills into the project that holds them).

Then install the programs in [TOOLS.md](TOOLS.md) for the skills you use. [CATALOGUE.md](CATALOGUE.md)
lists every skill and where it sits.

## What works where

- **Generic skills** (`generic` in the catalogue) work on any machine: game-ui (drive a game window,
  OCR), game-sources (manuals as searchable text, wiki fetching, Steam library), wiki-scout (find and
  pull wikis and publisher rules gently, text only), learn-a-game (how Claude learns a game),
  borrow-from-games (games as a parts bin for designing new ones), obs-record, skills-manager.
- **Game guides** (`<prefix>-guide`) carry the game's rules map and core loop in Claude's words. They
  point to manuals and files in the game's folder (`<workspace>/Games/<Genre>/<Game>/`, the same
  folder here): put your own copies there, or tell Claude where they are.
- **Dominions 6 skills** (dom6-*) are the deepest; the inspector's data must be built from your own game.
- Paths written `<workspace>` mean the folder the skills were built in; `~` is your home folder.

## Layout

The same tree as the workspace it came from: games by genre (the genre name carries the theme, and
computer and paper games are apart: `Wargames/` vs `Tabletop Wargames/`), publisher groups (`Paradox/`,
`AGEOD and Byzantine Games/`), theory shelves.
```
.claude/skills/<name>/                          generic skills (any game)
Games/<Genre>/<Game>/.claude/skills/<name>/     one game's skills
Military Theory/, Economic Theory/              shelf skills
Games/Fantasy Strategy/Dominions 6/spritestudio/, .../Maps/mapgen/   standalone tools
CATALOGUE.md  TOOLS.md  LEFT-OUT.txt            generated list, requirements, what the export skipped
```

This repository is generated by `skills-manager/scripts/export.py`; edit the skills at the source, not here.
