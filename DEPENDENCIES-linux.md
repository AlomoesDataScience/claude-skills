# Dependencies - Linux

Generated by `skills-manager/scripts/deps.py` from the scripts themselves (the Used by column is
what the code calls). Everything is free. Commands are Debian/Ubuntu/Mint (apt) and Flathub; other
distributions have the same packages. Install the core, then what the skills you use need.
Windows: see [DEPENDENCIES-windows.md](DEPENDENCIES-windows.md).

## Core (everything)

| Dependency | Install | Used by |
|---|---|---|
| Claude Code | `curl -fsSL https://claude.ai/install.sh \| bash` (docs.claude.com) | everything |
| Python 3.10+ | `sudo apt install python3` | everything |
| git | `sudo apt install git` | dom6-inspector, dom6-pretender, skills-manager |

## Per game

The games themselves (Steam, GOG, ...) and their manuals are not included: each `<prefix>-guide`
reads your own install and documents. dom6-inspector's data is rebuilt from your own Dominions 6 with
its `scripts/build.py` (git + Firefox).
